Product Release Workflow:

All product teams follow a standardized four-stage release workflow consisting of Planning, Development, QA, and Launch. Release plans must be documented in Productboard at least four weeks before development begins. The QA phase requires a minimum seven-day testing cycle that includes regression checks, accessibility validation, and device compatibility testing. Launch announcements should be submitted to the Communications team using the Release Messaging form at least 72 hours before the scheduled release date. Once all approvals are complete, a corresponding entry must be added to the Release Calendar on Confluence.


Customer Support Escalation Levels:

Support inquiries move through a three-tier escalation model designed to ensure timely resolution. Tier 1 handles basic troubleshooting and frequently asked questions. Tier 2 manages more complex technical issues such as API failures, integration errors, and data inconsistencies. Tier 3 involves engineering support for system bugs, outages, or security incidents. Priority-one issues must be escalated through the Critical Incident Zoom channel immediately, with an incident lead assigned within fifteen minutes. All escalation steps must have an accompanying JIRA ticket for tracking.


Design Asset Guidelines

All design teams should reference approved brand components located in the Brand Hub Figma workspace when creating marketing or product materials. Headline text must use Inter Bold at 32px, while body text uses Inter Regular at 16px. Product screenshots should be captured using the light-mode UI theme unless explicitly directed otherwise. Final files should be exported as WebP for web use and PNG for print. When submitting assets for review, always include a link to the original Figma file for version control.


Travel & Booking Procedures:

All business-related travel must be arranged through the corporate travel portal. Domestic travel requires approval from a direct manager, while international travel requires approval from both a manager and the Finance team. Per-diem rates are automatically applied based on the travel destination. Employees must submit travel reimbursements within ten days of returning and attach itemized receipts for all expenses. Any travel outside the approved itinerary must be documented and justified in the reimbursement submission.


Data Access & Permissions:**

Requests for access to internal datasets, dashboards, and APIs must be submitted through the centralized Access Request Portal. Each submission must include a clear business justification, specify the sensitivity level of the requested data, and define the duration for which access is needed. Requests involving customer-identifiable information require an InfoSec review before approval. All granted permissions automatically expire after ninety days unless renewed through the same request process.
